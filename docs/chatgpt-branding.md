# ChatGPT branding

On 20 September 2026, the personal Pro interface offered logo upload only during
custom plugin creation. Its existing-plugin Manage menu offered name/description
edits but no icon control.

A branded connection named **Career** now uses the same existing private tunnel
and AWS database as **Career Search MCP**. Both replacement career agents verified
get_job_detail and show_application_tracker through Career. Prefer Career; treat
the original connection as a compatibility alias, not an independent job source.
No backend migration, additional cloud service or application-data copy was needed.

The form required PNG under 10 KB. The uploaded icon was an 80px PNG (7,847 bytes),
resized from the generated master. Logo display was visually verified on both the
connected settings page and the plugin profile. The original connection was retained
so previous conversations keep resolving their references.
